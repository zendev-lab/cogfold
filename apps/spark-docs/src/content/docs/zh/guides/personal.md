---
title: 个人插件
---

个人插件使用显式绑定的 Hub 账号。本地 daemon 身份可在未绑定 Hub 时独立使用。设备注册不自动授予个人数据访问权。换绑前必须撤销旧绑定，换绑不转移已有记录。物品、个人待办与订阅独立启用，主数据由 Hub 托管；不支持离线写入或分布式同步。

## 关联设备

在 Hub 打开 `/personal` 并登录。本机用户可显式选择本机 Hub 账号。为已注册的
设备生成配对码，再在该设备的本地 Web 打开 `/personal`，输入 Hub 地址与配对码。
配对码十分钟后过期，兑换时还需校验该设备的注册凭据。

各个人工具独立启用。在关联设备上开始个人会话，或为指定工作区会话显式授予
某个工具的只读或读写权限。消息平台会话不能获得这些授权。撤销对后续请求立即
生效。个人会话不进入 Hub 通用会话列表，即使本机访问也必须登录其所属账号。

## 物品插件

启用物品后，`/personal/inventory` 和 daemon 的 `inventory` 工具使用同一份 Hub 数据。支持增删改查、状态和标签筛选、成本统计及月度购买趋势。金额保留原始单位，不推断币种；当前资产值表示仍持有物品的购买成本。更新和删除需要当前版本，旧页面发生冲突时请先刷新核对。停用插件保留数据并立即关闭访问。

## 个人待办

启用后使用 `/personal/todos` 或 `personal_todo` 工具。支持状态、优先级、截止日期、工时、父子与依赖关系。关系必须属于当前用户且不能成环；删除前先解除引用。完成任务记录完成时间，重新打开清除完成时间。筛选同时作用于列表和统计，已取消任务不计入逾期。

## 订阅

启用后使用 `/personal/subscriptions` 或 `subscription` 工具。续订按下次付款日期推进一个日历周期，月末会约束到目标月最后一天，终身订阅不可续订。取消订阅同时关闭自动续订。费用按币种分别估算，沿用每月 30 天、每年 365 天的成本口径，不自动换汇。累计费用不是付款账本。提醒天数仅作为数据保留，没有后台提醒任务。
