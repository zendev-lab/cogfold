---
title: 个人插件
---

个人插件使用显式绑定的 Hub 账号。本地 daemon 身份可在未绑定 Hub 时独立使用。设备注册不自动授予个人数据访问权。换绑前必须撤销旧绑定，换绑不转移已有记录。物品、个人待办与订阅独立启用，主数据由 Hub 托管；不支持离线写入或分布式同步。

## 关联设备

在 Hub 打开 `/personal` 并登录。本机用户可显式选择本机 Hub 账号。为已注册的
设备生成配对码，再在该设备的本地 Web 打开 `/personal`，输入 Hub 地址与配对码。
配对码十分钟后过期，兑换时还需校验该设备的注册凭据。

各个人工具独立启用。在关联设备上开始个人会话，或为指定工作区会话显式授予
某个工具的只读或读写权限。消息平台会话不能获得这些授权。撤销对后续请求立即
生效。个人会话不进入 Hub 通用会话列表，即使本机访问也必须登录其所属账号。
