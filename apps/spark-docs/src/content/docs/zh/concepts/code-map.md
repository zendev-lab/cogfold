title: 交互式代码地图
description: 探索 Spark 模块，并沿工作流程查看源码证据。
---

[打开交互式代码地图](/codemap/codemap.html)，探索 Spark 背后的源码。
选择模块可以查看职责、关联模块、源码文件和代表性测试。可以按模块名或文件路径
搜索，也可以沿五条有序工作流程逐步浏览。

运行时视图描述数据与控制流，构建视图展示包依赖，两者表示不同关系。
列出的测试只是源码中的声明，不代表测试已经通过或模型服务当前可用。

使用 **查看所选模块详情** 可以直接跳到所选模块的详情。
流程和关系链接会清除搜索过滤，并将键盘焦点移到详情面板。地图支持键盘导航和
窄屏布局。

源码链接打开记录的 Git 版本。在源码目录中，也可以直接打开独立的
`docs/codemap/codemap.html`，通过本地链接阅读文件，无需开发服务器。
地图的源码、证据边界和重新生成方式见仓库中的
[地图维护说明](https://github.com/zendev-lab/cogfold/tree/main/docs/codemap)。
